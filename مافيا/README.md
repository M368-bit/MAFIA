# 🎮 MAFIA NIGHT — لعبة مافيا أونلاين متكاملة

**الشعار:** اكشف الخائن... أو اخدع الجميع.

تطبيق ويب متكامل للعبة مافيا جماعية (Multiplayer Mafia) يعمل بشكل حقيقي عبر الإنترنت مع مزامنة فورية بالكامل باستخدام WebSockets (Socket.IO)، مع دعم كامل للغة العربية واتجاه RTL، وتصميم سينمائي داكن بلمسات بنفسجية.

---

## 🛠️ البنية التقنية (Tech Stack)

- **الواجهة الأمامية (Frontend):** React, TypeScript, Vite, Tailwind CSS, Lucide Icons.
- **الخادم (Backend):** Node.js, Express, Socket.IO.
- **الصوت (Voice Chat):** WebRTC حقيقي مع إشارات Socket.IO ودعم خوادم STUN العامة (Google STUN).
- **قاعدة البيانات / الحالة (State Management):** In-memory Map مع دعم التوسع لـ Redis/PostgreSQL.

---

## 🎭 الأدوار المتاحة في اللعبة

1. **المافيا (Mafia):** تتواصل سرًا في الليل وتختار ضحيتها.
2. **المواطن (Citizen):** يناقش ويصوت نهارًا لكشف الخونة.
3. **المحقق (Detective):** يتحقيق سريًا في هوية لاعب كل ليلة.
4. **الطبيب (Doctor):** يحاول إنقاذ لاعب من هجوم المافيا كل ليلة.

## 🚀 طريقة التشغيل محليًا (Local Installation & Running)

### المتطلبات الأساسية
- Node.js (الإصدار 18 أو أحدث)
- npm أو yarn

### الخطوات:

1. **تشغيل الخادم (Server):**
   ```bash
   cd server
   npm install
   npm run dev
   ```
   *(سيعمل الخادم على المنفذ `4000`)*

2. **تشغيل الواجهة الأمامية (Client):**
   ```bash
   cd client
   npm install
   npm run dev
   ```
   *(ستعمل الواجهة على المنفذ `3000` وتتصل تلقائيًا بالخادم)*

---

## 🧪 اختبار اللعبة بين متصفحات متعددة

1. افتح متصفحك العادي (مثل Google Chrome) وانتقل إلى `http://localhost:3000`.
2. أدخل اسمك وصورتك الرمزية، ثم انقر على **"إنشاء غرفة جديدة"**.
3. انسخ رمز الغرفة أو رابط الدعوة.
4. افتح نافذة متصفح مخفي (Incognito) أو متصفح آخر (مثل Firefox أو Edge) وانتقل إلى `http://localhost:3000`.
5. انضم إلى الغرفة باستخدام الرمز.
6. انقر على "جاهز" من النافذة الثانية، ثم اضغط على **"بدء المباراة"** من المضيف.
7. جرب مرحلة الليل والنهار والتصويت والدردشة النصية والصوتية الحقيقية عبر WebRTC.

## 📦 النشر والاستضافة (Deployment Guide)

### 1. استضافة الخادم (Backend - Render / Railway)
- ارفع مجلد `server` إلى مستودع GitHub.
- أنشئ مشروعًا جديدًا على [Render](https://render.com) أو [Railway](https://railway.app).
- حدد أمر البناء: `npm install`
- حدد أمر التشغيل: `npm start`
- أضف متغير البيئة `PORT=4000` (أو اتركه لتحديده تلقائيًا).

### 2. استضافة الواجهة الأمامية (Frontend - Vercel / Netlify)
- ارفع مجلد `client` إلى مستودع GitHub.
- انشر على [Vercel](https://vercel.com) أو [Netlify](https://netlify.com).
- تأكد من توجيه عنوان خادم Socket.IO في إعدادات الاتصال إلى رابط الخادم المنشور على Render/Railway.
